Lecciones

Ejemplos por día del curso JavaScript Intermedio (REDEC-UNAM / FESC), todos en el dominio de un gestor de tareas.

Ir a la app final (Task Manager)

Las demos de esta página se ejecutan en el navegador. Los ejemplos que solo usan Node se leen en GitHub y se ejecutan con node archivo.js desde el repositorio. Cada día tiene su README con explicación, salida esperada y ejercicios.

Día 1 — Fundamentos avanzados

Event loop, hoisting y scope, closures y this. Ejemplos de Node, sin demo de navegador.

  • Código y README en GitHub

Día 2 — POO y ES6+

Prototipos, clases, desestructuración, spread y rest, módulos ESM. Ejemplos de Node.

  • Código y README en GitHub

Día 3 — Programación asíncrona

Callbacks, promesas y async/await (Node) y Fetch API (navegador).

  • Demo: Fetch API con errores y cancelación
  • Código y README en GitHub

Día 4 — DOM avanzado y eventos

Delegación de eventos, Web Storage, formularios con FormData y textContent frente a innerHTML.

  • Demo: los cuatro temas en una página
  • Código y README en GitHub

Día 5 — Testing y buenas prácticas

Pruebas con Jest, guía de DevTools y patrones de diseño. Se ejecutan con npm test.

  • Código y README en GitHub
